Secret Santa 🎅

Draw names, then send each person their own private link on WhatsApp. Only they'll see who they're buying for, and that includes you.

Step 1

Who's taking part?

One name per line. Add or remove people as needed.

Pairs who shouldn't draw each other (optional)

For example, partners or relatives. Write one pair per line, like Andy, Ben. Neither of them will draw the other.

The links have to point at a public copy of this page. It fills in by itself once the page is online.

Step 2

Send the links

Tap WhatsApp next to each name and choose that person's chat. Every link only works for the person it belongs to, so don't post them in the group chat. You won't see any matches on this screen.

This page is open from a file on your computer, so the links won't open on anyone's phone. Put the page online first (see the README), then draw again from there.
    Everyone's been sent their link. Merry Christmas! 🎄

    This draw is saved in this browser, so you can close the page and come back to finish sending. If you redraw, all the old links stop matching the new draw, so you'd need to resend everyone's.

    Open source (MIT) · Runs entirely in your browser · No logins, no tracking, nothing stored on a server
